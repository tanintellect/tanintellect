## 🔨 What I'm Building

### [Flowlee](https://github.com/tanintellect) — Neuroscience-Based Focus Tracker
> `Tauri` `React` `SQLite` `Gemini Flash`

A personal Windows desktop app that treats your focus the way athletes treat training. Not another Pomodoro timer.

- **AI Readiness Assessment** — knows if you're actually ready to focus before you start
- **Distraction Forensics** — tracks *why* you lost focus, not just *when*
- **Session Archaeology** — retrospective analysis of your deep work patterns
- **Experiment Mode** — structured n=1 personal trials with statistical tracking
